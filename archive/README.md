# Archive

Earlier experiments, kept for history. Not maintained and not wired into the game; the tools here import the old `archive/lander/sim.mjs` and `server.mjs` (copies of the code before the 3-mode cleanup) and may need path fixes to run.
Includes: scene modes s1–s5 (the model picks raw controls from prose; 0/6), joystick wording, hints/physics/coarse/hybrid/facts variants, multi v1, the rival lander and race tool, steering benches and probes. Their logs are in `results/`.
